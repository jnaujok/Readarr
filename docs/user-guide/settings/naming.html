File naming

Open Settings → Media Management and edit the naming format. The naming token picker includes the tokens below (examples are from the picker).

Fallbacks

Any token can take a fallback after a pipe. If the token is empty, Readarr uses the fallback text. Example from the picker: {Book Series|Standalone} → Standalone when the book is not in a series.

Book tokens added in this rewrite

TokenPicker example
{Book TitleNoEdition}The Book's Title!: Subtitle!
{Book CleanTitleNoEdition}The Books Title!: Subtitle
{Book SeriesPosition:00}01
{Isbn}9781234567890
{Asin}B00EXAMPLE
{Narrator}Jane Doe

{Narrator} comes from audio tags when a NARRATOR field is present (ID3, Xiph, or iTunes).
