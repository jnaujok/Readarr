Quality profiles

Open Settings → Profiles. Each profile has a name, allowed qualities, optional upgrades, and Wanted Formats.

  1. Set Name.
  2. Enable the qualities Readarr may grab (EPUB, AZW3, PDF, MP3, and so on).
  3. Set Upgrades Allowed if Readarr should replace a lower quality with a higher one in the same format kind. Help text: “If disabled qualities will not be upgraded.”
  4. If upgrades are on, set Upgrade Until. Help text: “Once this quality is reached Readarr will no longer download books.” That cutoff applies inside a format kind, not across ebook versus audiobook.
  5. Set Wanted Formats as described in Wanted formats.

The profile card lists selected wanted formats as labels: Ebooks (EPUB, AZW3, MOBI), PDFs, Audiobooks.

New default profiles created on a first run select matching wanted formats (ebook profile wants ebooks; spoken profile wants audiobooks). Existing profiles stay on the old any-file behaviour until you check boxes.
