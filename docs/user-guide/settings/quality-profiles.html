Quality profiles

Open Settings → Profiles. The heading is Quality Profiles. A fresh instance shows an eBook card (MOBI, EPUB, AZW3) and a Spoken profile for audio. The same page also has Metadata Profiles, Delay Profiles, and Release Profiles.

  1. Set Name.
  2. Enable the qualities Readarr may grab (EPUB, AZW3, PDF, MP3, and so on).
  3. Set Upgrades Allowed if Readarr should replace a lower quality with a higher one in the same format kind. Help text: “If disabled qualities will not be upgraded.” Default profiles on this capture have upgrades off.
  4. If upgrades are on, set the cutoff. Help text: “Once this quality is reached Readarr will no longer download books.” That cutoff applies inside a format kind, not across ebook versus audiobook.
  5. Set Wanted Formats as described in Wanted formats.

When you check wanted formats, the profile card lists them as Ebooks (EPUB, AZW3, MOBI), PDFs, and/or Audiobooks. Until you check those boxes, any allowed file still completes the book.
