Media management

Open Settings → Media Management. Use the toolbar button Show Advanced to reveal advanced fields, including the Folders fieldset.

LabelHelp text
Create empty author foldersCreate missing author folders during disk scan
Omit author folder on renamePlace renamed files in the parent of the author folder instead of inside the author folder
Delete empty foldersDelete empty author folders during disk scan and when book files are deleted

On a fresh instance those three options are off. Naming formats are on the same page under Book Naming. See File naming.
