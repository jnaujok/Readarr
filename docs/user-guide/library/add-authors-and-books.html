Add authors and books

Open Library → Add New. Search, then add an author or a book.

Add an author

  1. Choose a root folder, monitor option, quality profile, and metadata profile.
  2. Set Automatically Switch Edition if you want Readarr to pick the edition that best matches downloaded files. This is on by default. Help text: “Readarr will automatically switch to the edition best matching downloaded files.”
  3. Optionally start a search for missing books, then add the author.

Add a book

If the author is already in the library, the add-book dialog can set Automatically Switch Edition for that book. If the author is new, the same author options as above appear, including Automatically Switch Edition.

Edit a book later

On a book, open edit. You can change Monitored, Automatically Switch Edition, and wanted formats for that book.
