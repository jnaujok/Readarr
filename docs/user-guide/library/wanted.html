Missing and cutoff

The sidebar Wanted group has two lists:

ItemMeaning
MissingMonitored books that are still missing a collected copy. If wanted formats are set, the book stays here until every selected format has a file.
Cutoff UnmetBooks that have a file below the profile cutoff, so Readarr may still upgrade that format.

On Books, the Missing filter also treats a book as missing when any selected format is absent.
