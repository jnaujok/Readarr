User guide / Getting started

Start here

Use this page after you have a Readarr process running. The default web UI is on port 8787 unless you changed it.

First-run jobs

  1. Open Readarr in a browser.
  2. Set authentication under Settings → General if the instance is reachable from other machines.
  3. Confirm the metadata URL under Settings → Development. Leave it blank to use rreading-glasses at https://api.bookinfo.pro.
  4. Add a root folder under Settings → Media Management.
  5. Review Settings → Profiles. Choose whether each quality profile should collect ebooks, PDFs, and audiobooks independently. See Wanted formats.
  6. Add indexers and download clients under Settings.
  7. Add authors from Library → Add New.

Build from source

On a development machine with the .NET 10 SDK:

export PATH="$HOME/.dotnet:$PATH"
dotnet build src/Readarr.sln -c Release

The default git branch is develop.
