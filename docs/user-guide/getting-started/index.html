User guide / Getting started

Start here

The default HTTP port is 8787. Some deployments map a second instance to another port (this capture used 8788). Open the URL in a browser.

First start: Authentication Required

On a new instance the library loads, then a modal titled Authentication Required blocks the rest of the UI until you save a method.

  1. Read the warning: “To prevent remote access without authentication, Readarr now requires authentication to be enabled. You can optionally disable authentication from local addresses.”
  2. Set Authentication Method to something other than None. With None selected the form shows Please select a valid authentication method.
  3. Leave Authentication Required as Enabled unless you understand the risk stated on the form: “Change which requests authentication is required for. Do not change unless you understand the risks.”
  4. Enter Username, Password, and Password Confirmation.
  5. Choose Save.

After that, later visits use the login page.

Then finish setup

  1. Confirm the metadata URL: open Settings (the hub page), then Development. Leave Metadata Source blank for rreading-glasses. See Metadata source.
  2. Add a root folder under Settings → Media Management (fieldset Root Folders).
  3. Review Settings → Profiles. Default cards on a fresh instance are eBook (MOBI, EPUB, AZW3) and Spoken. Set Wanted Formats if you want independent ebook, PDF, and audiobook copies. See Wanted formats.
  4. Add indexers and download clients from the Settings hub.
  5. Add authors from Library → Add New.

Build from source

On a development machine with the .NET 10 SDK:

export PATH="$HOME/.dotnet:$PATH"
dotnet build src/Readarr.sln -c Release

The default git branch is develop.
