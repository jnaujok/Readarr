Metadata source

Author and book metadata does not come from the retired Servarr API. The default provider is rreading-glasses. Development is on the Settings hub page, not in the Settings sidebar list.

  1. Open Settings (sidebar), then the Development link on that hub page. The summary text is “Metadata provider source (rreading-glasses by default) and logging”.
  2. In Metadata Provider Source, set Metadata Source.
  3. Leave the field blank to use https://api.bookinfo.pro. A fresh instance stores an empty value, which is that default.
  4. To use Hardcover, enter https://hardcover.bookinfo.pro.
  5. To use a self-hosted rreading-glasses instance, enter that URL. Do not append /v1.

Help text on the field: “Override the metadata provider URL. Leave blank to use rreading-glasses at https://api.bookinfo.pro. Self-hosted instances and Hardcover (https://hardcover.bookinfo.pro) are also supported.”
