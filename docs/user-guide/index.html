Readarr user guide

Readarr is an ebook and audiobook collection manager for Usenet and BitTorrent. It watches authors you follow, grabs releases, and sorts files into your library. This fork is a rewrite of the retired Servarr project on .NET 10. Metadata comes from rreading-glasses by default.

This guide is for operators of a Readarr instance. Labels match the English UI. Captures are from Readarr 0.4.19.51 (develop), runtime .NET 10, SQLite.

Getting started Authentication Required, sign in, metadata source. Wanted formats Keep an EPUB, a PDF, and an audiobook of the same title. Add authors and books Search, monitor, and automatic edition switching. Quality profiles eBook / Spoken cards, upgrades, wanted formats.

What this fork changes

  • Runs on .NET 10.
  • Uses rreading-glasses (https://api.bookinfo.pro) instead of the retired Servarr metadata API. Set the URL under the Settings hub → Development.
  • Collects ebook, PDF, and audiobook copies independently when you check Wanted Formats on a quality profile (or override one book).
  • Adds naming tokens (fallbacks, title without edition, ISBN/ASIN/narrator), Map Selected on Unmapped Files, and Omit author folder on rename.
