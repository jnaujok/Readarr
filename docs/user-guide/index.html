Readarr user guide

Readarr is an ebook and audiobook collection manager for Usenet and BitTorrent. It watches authors you follow, grabs releases, and sorts files into your library. This fork is a rewrite of the retired Servarr project on .NET 10. Metadata comes from rreading-glasses by default.

This guide is for operators of a Readarr instance. Labels match the English UI.

Getting started Install, first run, and the metadata source. Wanted formats Keep an EPUB, a PDF, and an audiobook of the same title. Add authors and books Search, monitor, and automatic edition switching. Quality profiles Allowed qualities, upgrades, and wanted formats.

What this fork changes

  • Runs on .NET 10.
  • Uses rreading-glasses (https://api.bookinfo.pro) instead of the retired Servarr metadata API.
  • Collects ebook, PDF, and audiobook copies independently when you ask for them.
  • Adds naming tokens, unmapped-file bulk mapping, and several library fixes from the archived Readarr issue list.
About this guide. Procedures use the labels in the Readarr UI source (English). Screenshots were not taken from a running instance in this pass.
